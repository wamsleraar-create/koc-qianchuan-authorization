## 注意

- 先用 1 个 KOC 账号试跑。
- 测试反馈群优先使用单独测试群，避免影响正式业务群。
- 客户账户 ID 优先于账户名称，用于避免同名账户误选。
- 验证码、扫码、短信验证需要人工处理。
- 正式计划提交前需要群内确认；测试计划提交也必须有明确授权。
